# Web Organizador de Tareas

Un administrador de tareas sencillo y minimalista desarrollado para organizar pendientes diarios de forma eficiente.

## Caracteristicas
* Agregar tareas: Guarda nuevos pendientes rapidamente.
* Marcar como completadas: Tacha las tareas que ya realizaste.
* Eliminar tareas: Limpia tu lista borrando los pendientes obsoletos.
* Diseno responsivo: Adaptado para visualizarse correctamente en computadoras y dispositivos moviles.

## Tecnologias utilizadas
* HTML5: Estructura semantica del sitio.
* CSS3: Estilos de la interfaz de usuario y diseno fluido.
* JavaScript (Vanilla): Logica del negocio y manipulacion del DOM.

## Instalacion y uso
No requiere ninguna instalacion compleja ni servidores locales.

1. Clona este repositorio en tu maquina local:
   ```bash
   git clone https://github.com
   ```
2. Abre la carpeta del proyecto.
3. Haz doble clic en el archivo `index.html` para abrir la aplicacion en tu navegador web.
